# Code

This folder contains the following scripts:

- `s01_extract_hex_colours.R`: this script is used to extract RGB and hex triplet values from the digital photograph of the erythristic barred grass snake. Data such as pixel coordinates and R objects used to recreate the same results are saved into `data/intermdiate`, while the resulting colour values are saved into the `results` folder
- `s02_table_colour_swatch_figure_1c`: this script is used to generate the panel "c" of Figure 1.
