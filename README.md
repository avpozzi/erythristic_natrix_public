# First record of erythrism in the barred grass snake Natrix helvetica (Lacepéde, 1789) from Great Britain

This repository contains the code and results used for the preparation of the manuscript "First record of erythrism in the barred grass snake Natrix helvetica (Lacepéde, 1789) from Great Britain" submitted to the Herpetological Bulletin. 

The repository follows the following structure:
- `code` folder: contains the code used during the analyses. The scripts are named as SXX_scriptname, where SXX indicates the order in which the scripts should be run.
- `data\raw` folder: contains raw data used during the analyses.
- `data\intermediate` folder: contains data at the intermediate stage produced by the analyses.
- `results` folder: contains the final results.
